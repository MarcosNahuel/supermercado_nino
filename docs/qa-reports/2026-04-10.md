## Issues Encontrados y Corregidos

### Issue #1 — VTEX API endpoint devuelve 400 Bad Request [Crítico]

**Detección:** Smoke test real del scraper contra Carrefour.

**Error:**
```
400 Client Error: Bad Request for url:
https://www.carrefour.com.ar/api/io/_v/api/intelligent-search/product_search/?query=BEBIDAS&page=0&count=50&locale=es-AR
```

**Causa raíz:** El endpoint `intelligent-search/product_search` requiere cabeceras especiales (cookies de sesión VTEX) que no son fáciles de obtener sin autenticación.

**Fix aplicado:** Cambio al endpoint legacy estable `catalog_system/pub/products/search` que funciona sin autenticación en todas las cadenas VTEX probadas (Carrefour, Jumbo, Disco). También se agregó helper `_extract_teaser_name` para manejar el formato legacy .NET (`<Name>k__BackingField`) además del formato moderno.

**Commit:** `0228256` — `fix(competitive): use VTEX catalog_system endpoint (fixes 400 error)`

**Verificación:** Smoke test real scrapeó 50 productos de Carrefour BEBIDAS con 35 promos detectadas (Tarjeta Carrefour 15%, Cuenta Digital 15% Off Viernes). Tests unitarios (4/4) siguen pasando.

### Issue #2 — KeyError: 'precio_promedio' no existe cuando solo hay datos VTEX [Crítico]

**Detección:** Dashboard cargado con data VTEX real, click en tab "Inteligencia Competitiva".

**Error:**
```
KeyError: "Column(s) ['precio_promedio'] do not exist"
File: src/competitive/insights_engine.py:73, in find_promo_opportunities
```

**Causa raíz:** La función `find_promo_opportunities` agrega por `precio_promedio`, columna que solo existe en datos SEPA. Cuando `compute_price_comparison` recibe solo data VTEX (como en el smoke test), VTEX tiene `precio_venta` pero no `precio_promedio`.

**Fix aplicado:** En `product_matcher.compute_price_comparison`, rama VTEX: agregar alias `precio_promedio = precio_venta` para unificar schema entre fuentes.

**Commit:** `6c40712` — `fix(competitive): normalize precio_promedio for VTEX-only data`

**Verificación:** Pipeline end-to-end ejecutó OK (35 productos matcheados, 97.1% competitivos, 35 promos detectadas). Dashboard renderiza los 4 tabs con datos reales. Tests (8/8 entre matcher e insights) siguen pasando.
